# FitZone — Gym & Fitness Website

A responsive, front-end gym and fitness website built with HTML, CSS, and JavaScript. This project demonstrates common web development fundamentals in a single-page layout.

## Features

- Responsive navigation and page sections for Home, Workouts, Plans, Nutrition, and Join
- Workout cards with images and descriptions
- Membership plans displayed in a table
- BMI calculator with basic input validation
- Membership-plan selector with dynamic messages
- Demo join form with browser-side confirmation
- Responsive styling for desktop and smaller screens

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser. For live reload while editing, you can use the Live Server extension in Visual Studio Code.

No package installation or build step is required.

## Notes and limitations

- This is a front-end educational project. The join form only displays a confirmation in the browser; it does not save or send registration details to a server.
- Images are loaded from Unsplash, so an internet connection is required to display those remote images.
- The BMI calculator is a basic informational demonstration and is not a medical assessment.
